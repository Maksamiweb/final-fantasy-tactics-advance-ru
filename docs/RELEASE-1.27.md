## Android Recomp: readable-font preview, arm64

FFTA-Recomp-RU-readable-font-clean.apk — сборка без встроенных ROM,
сохранений и тестовых состояний. При новой установке начинается с пролога.
Обновление поверх уже установленного приложения сохраняет его данные:
пакет org.gbarecomp.fftarecomp. Не удаляйте свои сейвы ради чистого теста.
Это отладочная предварительная сборка, подписанная debug-ключом.

Внимание: этот APK пока привязан к ROM audit-1.26. Подготовьте его из того
же чистого USA ROM с прилагаемым FFTA-USA-RU-demo-1.26.bps и выберите
в приложении. SHA-1 результата ff29faf0da37332e77524236f6966633ec51139d.
ROM 1.27 предназначен для GBA/эмулятора и этим APK пока не принимается.
Одинаковые новые буквы APK подставляет при отрисовке через свой адаптер.

В APK также добавлена окантовка обрезанных краёв окон широкого экрана.
Это оформление края, а не восстановление скрытого рисунка портретов.
Отключены LCD/dither и MMPX; включён резкий масштаб.
Старое быстрое состояние может содержать прежние пиксели букв: закройте
и снова откройте окно. Между эмуляторами переносите обычное игровое
flash-сохранение 65 536 байт, а не быстрые состояния.
