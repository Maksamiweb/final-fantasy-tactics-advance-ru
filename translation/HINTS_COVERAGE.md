## Содержательные проверки

Сохранены причины штрафов и бонусов, ранги R1–R7, различие запрета/поощрения, исключения для стихийного оружия, наказание/награда лишь инициатору комбо, порог области от двух клеток. Исходные расхождения рангов между законом и картой сохранены: менять игровое правило по догадке нельзя. Полный отчёт — `reports/hints-coverage.json`.

У fx_text/17/39 и /212 английский глагол собран из `Remedi` и `es`. Теперь он переведён целым русским глаголом. Общая строка имени не менялась. Исключение `literalize_word_fragment` разрешено только для этих двух ID, точных исходных SHA-256 и ожидаемого суффикса. Все остальные структурные функции должны совпадать. Это поддерживается одним методом в сборщике и проверке; метаданные сохраняются при подготовке. E0030 закрыта на уровне текста и ресурсного обратного чтения, игровой вывод не проверен.

Ритц и Шара в специальных отчётах говорят в женском роде; Бабус, Эзель и Сид — в мужском. Динамические имена обычных бойцов не склоняются. Условия победы и поражения сохранены раздельно, включая различие тюрьмы и KO главного героя. Предупреждение об удалении данных при loading в fx_text/1/38 сохранено по источнику; контекст вызова ещё нужно установить (E0035).

Словарь 0.11: 614 карточек, 125 accepted / 489 review. Добавлены 57 LOCAL proposal: рабочие названия групп команд, карт и несколько имён из новостей. ## Технические проверки и ограничения

При подготовке текста все 5 442 буфера закодированы и прочитаны обратно **в памяти**. Позднее по прямому запросу пользователя собран ROM 0.8; весь каталог из 16 195 записей прошёл обратный разбор. Совпали нормализованные токены и структурные функции, кроме двух разрешённых словесных замен. Сохранён неизвестный исходной карте глиф 0x1E6 в двух местах 8/88; его внешний вид не объявляется установленным. Проверки — `reports/hints-encoding-check.json`, 21 unittest.

Обычные подсказки проверены по предварительным 156px / 3 строки. Большие страницы таверны и правила связи — по предварительным 156px / 7 строк; это ориентир по структуре исходника, не измерение реального окна. Все расчётные проверки пройдены после сокращений. Новые страницы/управляющие окна не добавлялись. 1B/1D и некоторые поля данных моделируются неполно.

Короткие сообщения и ответы хранятся без автопереноса в pending_label_files. Для вариантов, разделённых 42, измеряется максимум отдельного варианта, а не сумма. Для динамических значений есть только предварительный бюджет 42px. 80px — диагностический порог, не доказанный предел боевой строки. Новых коротких ресурсов 431, из них 357 шире этого порога по статическому тексту. Отдельно остаются прежние 417 названий меню.

В pending_fixed_files добавлены 8 записей: список навыков и 7 координатных страниц заданий. Сохранены исходное число строк и порядок функций, иконок, цветов, числовых подстановок. Их нельзя пропускать через обычный автоперенос. Реальные координаты и длинные значения ещё не проверены.

**Размеры справки для тестового ROM 0.8:** девять длинных страниц требуют 547–757 байт. Сопоставлены их исходные raw_len: 690–970 байт; каждый русский вариант короче собственного оригинала. Сборщик разрешает больший размер только для fx_text/8 и только в пределах исходной записи. Прочие ограничения не ослаблены. Полный ROM roundtrip пройден; вывод всех длинных страниц ещё не просмотрен. E0033 закрыта для тестовой вставки.

Последний ROM 0.8 включает все 5 442 записи. Вне сборки после следующего подхода — 814 новых записей и 2 редакторские замены. Прежний ROM 0.7 не перезаписан. Полное прохождение, игровые сохранения, графические подсказки и новая вёрстка не проверены.

## Как продолжать

Авторские `.ru.txt` компилируются инструментом `tools/import_draft.py`: формат `ID|русский текст`, `@` означает перевод строки. У обычных файлов окончания явно сохранены; для command-help, tutorial-notices, pub-tutorial-help, pub-information-help и pub-skills-help-fixed при импорте добавляются `[[40]][[42]]`. У service-help и mission-results числовые ID дополняются префиксом fx_text/4/ и fx_text/11/ соответственно. `ability-word-fragments.ru.json` — основной файл двух точечных исключений, его метаданные сохранять.

У battle-hints указываются `--prefix pages:battle/ --append [[42]]`, а точные повторы раскрываются только с частным каталогом и `--expand-prefix pages:battle/`. У law-help окончания уже в тексте; раскрытие ограничено `fx_text/23/` и `fx_text/24/`. Сопоставляются одновременно полный исходный текст и его semantic hash; английский текст не экспортируется.

`check_drafts.py` запускается с частным каталогом, исходным charset, чистым USA ROM и закреплённым PT Sans. Для большой справки использовать `--max-lines 7`, для коротких строк `--labels`, для координатных шаблонов `--fixed`. Выдача prepared — только текст, ROM не создаётся. `check_encoding.py` принимает объединённый список всех авторских ID и проверяет кодирование/декодирование в памяти. Дальше: исследовать E0033, проверить реальные окна и графические ресурсы; затем интегрировать и тестировать, когда сборка разрешена политикой пользователя.

Текущий общий счёт после продолжения перевода: 6 256 / 16 195 = 38,63%; см. EQUIPMENT_COVERAGE.md. Цифры раздела подготовки подсказок выше относятся к своему тематическому подходу.
