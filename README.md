# Final Fantasy Tactics Advance — русский перевод

Неофициальный любительский перевод **Final Fantasy Tactics Advance** (Game Boy Advance, версия USA) на русский язык.

**Перевод:** Maksami · техническая часть и черновая редактура — с помощью ИИ-ассистента.

На титульном экране — «РУССКАЯ ВЕРСИЯ» и «Перевод Maksami».

## Скачать

Патч — в разделе [Releases](../../releases/latest): `FFTA-USA-RU-demo-1.28.bps`.

Текущая сборка **audit-1.28** — рабочая версия, готовность около 95 %. Переведены все диалоги, меню, описания предметов, способностей и заданий, справка, доклады, большая часть графических надписей. Полного прохождения игры с переводом ещё не было — возможны отдельные непроверенные окна и редкие события.

## Обновление audit-1.28

Исправлена базовая линия строчной «б» — текст больше не выглядит прыгающим. Форма и ширина буквы не менялись; добавлена проверка общей линии для всех букв без выносных элементов. От 1.27 отличаются 32 байта. [Описание выпуска](docs/RELEASE-1.28.md).

## Обновление audit-1.27

Перерисованы все 132 русские буквы обычного и узкого шрифтов. Ширины и адреса текста сохранены. Только таблица глифов отличается от 1.26; новых текстов нет. Полное прохождение не проверено. [Описание выпуска](docs/RELEASE-1.27.md).

## Как применить патч

Нужен **собственный** образ картриджа американской версии. Проверьте его перед патчем:

| | Значение |
|---|---|
| Версия | Final Fantasy Tactics Advance (USA), код AFXE |
| Размер | 16 777 216 байт |
| CRC32 | `5645E56C` |
| SHA-1 | `4ac05441f4de70a4ec3dd932116346c61b8783d9` |

Европейская и японская версии не подойдут.

**Вариант 1 — Floating IPS (Windows):** скачайте [Flips](https://github.com/Alcaro/Flips/releases), нажмите *Apply Patch*, выберите `.bps`, затем ROM, сохраните результат под новым именем.

**Вариант 2 — в браузере:** [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) — выберите ROM и патч, нажмите *Apply patch*. Файлы никуда не отправляются, всё делается на вашем компьютере.

**Вариант 3 — RetroArch (софт-патч):** положите `.bps` рядом с ROM и назовите одинаково, например `FFTA.gba` и `FFTA.bps`. RetroArch применит патч при запуске, ROM не меняется.

Готовый ROM — 18 036 544 байта, CRC32 `9D4E31B6`.

Проверено в mGBA, Mesen 2 и RetroArch (Android). Сохраняйтесь через меню игры: сохранения состояния (save state) от английской версии могут не подойти.

## Что в переводе

- Имена, предметы, магия и места — по устоявшимся русским названиям серии Final Fantasy (Марш, Монблан, Ивалис, Эзель…).
- Живые диалоги, у бангаа — характерное шипение («Сстой!»).
- Где в оригинале брань скрыта символами — русская брань, к месту.
- Добавлены кириллические глифы; для длинных строк — компактный и узкий шрифты, всё подогнано под размеры окон.
- Переведена графика: титульное меню, заголовки окон, подписи на карте, месяцы календаря, «ПОБЕДА!», «ГОТОВЬТЕСЬ!», «ВПЕРЁД!», надписи статуса и др.
- Клавиатура ввода имени оставлена латинской (имя по умолчанию переведено).

## Что в репозитории

| Папка | Содержимое |
|---|---|
| `translation/` | Тексты перевода: сцены и разделы (`*.ru.json` / `*.ru.txt`), слои правок, полный снимок текущей сборки `ru-audit-1.26.json` |
| `translation/GLOSSARY.md`, `TERMINOLOGY*.md/json`, `NAME_INFLECTION_POLICY.md` | Глоссарий, реестр терминов с источниками, правила склонения имён и стиля |
| `tools/` | Инструменты: разбор и сборка текста, кодировка и перенос строк по ширине в пикселях, графика (LZSS, A7, 4bpp), BPS, проверки и тесты |
| `research/tools/` | Первый этап: сравнение версий USA/EU/JP и проверка вывода кириллицы |
| `docs/` | План перевода и подробный журнал работ (`PROGRESS.md`) |

Записи перевода привязаны к строкам игры по идентификаторам и SHA-256 исходных строк — самого английского текста в репозитории нет.

**В репозиторий не входят** ROM игры и любые его части: оригинальный текст, графика, шрифты. Все права на Final Fantasy Tactics Advance принадлежат SQUARE ENIX. Для работы инструментов нужна собственная копия игры.

Разбор формата текста опирается на проект [ffta_us_cn](https://github.com/BSoD123456/ffta_us_cn) (GPL-3.0): `tools/fetch_parser.py` скачивает закреплённую версию его парсера и таблицы символов, в репозиторий они не включены. Шрифты для отрисовки русских надписей (PT Sans и др.) тоже не включены.

Требования: Python 3.10+, `pip install -r requirements.txt` (Pillow). Тесты: `python -m unittest discover -s tools -p "test_*.py"`.

## Воспроизведение обновления шрифта

Текстовый снимок остался audit-1.26: в 1.27 меняется только шрифт. После сборки точной базы 1.26 наложите прилагаемую таблицу OFL-глифов:

    python tools/apply_readable_font.py path/to/audit-1.26.gba path/to/audit-1.27.gba

Скрипт проверяет SHA-256 базы и результата, не перезаписывает существующий файл. `font/readable/` содержит только производные русские глифы Maksami UI Sans, аудит и лицензии OFL; оригинальный шрифт игры не включён.
